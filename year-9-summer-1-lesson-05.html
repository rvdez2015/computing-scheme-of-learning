Learning and success criteria

  • Explain and apply the key idea in L14: Text Input and Output.
  • Demonstrate the required feature and justify a usable design choice with a test result.

Subject knowledge and resources

  • Show a small interface, webpage, slide or document with a clear audience task. Model one change and test whether a user can still complete the task.
  • Anticipated misconception: A visually polished design can still be difficult to use or inaccessible.
  • Prepare the worked example, a parallel pupil task and a model answer.

45-minute sequence

TimeTeaching and learning
0–5 minRetrieve one idea from L13: Labels, Buttons, and User Interaction and connect it to today’s lesson.
5–15 minShow a small interface, webpage, slide or document with a clear audience task. Model one change and test whether a user can still complete the task.
15–23 minWhich change made the task easier, and what test would tell you? Expected evidence: Demonstrate the required feature and justify a usable design choice with a test result. If pupils miss the key idea, re-model and ask a parallel question.
23–40 minCreate or improve a small artefact with the named feature. Test it against a user task and explain one improvement.
40–45 minAsk pupils to answer a fresh version of the check. Review their reasoning before planning the next lesson.

Adaptive teaching and challenge

  • Offer a partially worked model and a vocabulary reference where useful. Agree any individual adjustments before teaching.
  • Ask pupils to predict what changes when one input, rule or design choice is varied.
