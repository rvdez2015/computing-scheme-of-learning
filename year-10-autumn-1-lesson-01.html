1.1a - The CPU

Year 10 · Autumn 1 · 45 minutes

SLR 1.1 Systems Architecture OCR GCSE Specification.

Planning draft. Adapt resources and support for your class.

Learning and success criteria

  • Explain and apply the key idea in 1.1a - The CPU.
  • Identify the ALU and main memory and explain the difference between performing and storing.

Subject knowledge and resources

  • Run a three-card example in which a stored ADD instruction reaches the CPU. Label how the control unit coordinates the operation and the ALU performs it.
  • Anticipated misconception: The CPU processes instructions, while RAM stores active data and instructions.
  • Prepare the worked example, a parallel pupil task and a model answer.

45-minute sequence

TimeTeaching and learning
0–5 minElicit an example pupils already know and connect it to today’s lesson.
5–15 minRun a three-card example in which a stored ADD instruction reaches the CPU. Label how the control unit coordinates the operation and the ALU performs it.
15–23 minWhich part performs the addition, and where might the instruction have been stored before it was fetched? Expected evidence: Identify the ALU and main memory and explain the difference between performing and storing. If pupils miss the key idea, re-model and ask a parallel question.
23–40 minAnnotate a diagram showing CPU and RAM and explain how each contributes when a program adds two numbers.
40–45 minAsk pupils to answer a fresh version of the check. Review their reasoning before planning the next lesson.

Adaptive teaching and challenge

  • Offer a partially worked model and a vocabulary reference where useful. Agree any individual adjustments before teaching.
  • Ask pupils to justify an alternative or test a boundary case using precise technical language.

Targeted Teachers’ Standards

TS3 · 5–15 min · Subject knowledge

Make the technical idea explicit and check the anticipated misconception. Look for accurate terminology and pupils correcting the error. Misconception: The CPU processes instructions, while RAM stores active data and instructions.

TS6 · 15–23 and 40–45 min · Assessment

Compare the check and exit responses. Look for identify the ALU and main memory and explain the difference between performing and storing. Record how the teacher responds to errors.
