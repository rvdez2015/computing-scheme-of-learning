2.1 Data Representation

Planning draft. Check that the suggested example and assessment match this lesson title before teaching.

Learning and success criteria

  • Explain and apply the key idea in 2.4b(I) negative number representation unsigned and signed binary numbers, 2's Complement.
  • State the correct place value and show working that matches the requested operation.

Subject knowledge and resources

  • Use a short place-value grid and show each step in the required conversion or operation. Choose an example that exposes a boundary or carry.
  • Anticipated misconception: Binary place values are powers of two, and the rightmost whole-number column represents 1.
  • Prepare the worked example, a parallel pupil task and a model answer.

45-minute sequence

TimeTeaching and learning
0–5 minRetrieve one idea from 2.4b - Binary Addition & Shifts and connect it to today’s lesson.
5–15 minUse a short place-value grid and show each step in the required conversion or operation. Choose an example that exposes a boundary or carry.
15–23 minWhat is the value of the rightmost whole-number bit and how does that affect the calculation? Expected evidence: State the correct place value and show working that matches the requested operation. If pupils miss the key idea, re-model and ask a parallel question.
23–40 minSolve a parallel example, check by reversing the conversion where possible and explain one likely error.
40–45 minAsk pupils to answer a fresh version of the check. Review their reasoning before planning the next lesson.

Adaptive teaching and challenge

  • Offer a partially worked model and a vocabulary reference where useful. Agree any individual adjustments before teaching.
  • Ask pupils to justify an alternative or test a boundary case using precise technical language.
